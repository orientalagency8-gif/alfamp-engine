# Alfa MP Engine

Fork of [CitizenFX/fivem](https://github.com/citizenfx/fivem) with our rebrand patches + self-updater disabled.

## What this repo is

This is the **engine** that powers the Alfa MP game client (`AlfaMP.exe`). It's a true fork — we maintain our own commits, our own CI pipeline, and we're not bound to upstream availability.

## Build

Runs in GitHub Actions on `windows-latest`. See `.github/workflows/build.yml`.
